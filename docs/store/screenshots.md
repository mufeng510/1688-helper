# 商店截图清单（需你本人截图，尺寸建议）

> 截图不可由自动化伪造，需在真实浏览器中截取。Chrome Web Store：1280×800（也接受 640×400），至少 1 张，建议 3–5 张；Edge Add-ons：1280×800 / 1366×768。图标 128×128 已具备（dist/icons/icon-128.png）。

建议截取：

1. **管理页 · 总览**（manage.html#overview）：展示运行状态、监控商品数、理赔待办、扫描时间——体现「个人采购驾驶舱」。
2. **SKU 监控 · 商品列表/详情**（manage.html#sku）：列表 + 某商品 SKU 当前状态、历史快照/变化——核心卖点。
3. **1688 商品页 · 导入工作台卡片**（offer 详情页，FAB 展开后的预览确认卡片，含「更新已有商品/仍然新建」选项）——v0.4.0 亮点；若不便展示可用 mock 卡片截图。
4. **弹出窗 · popup「添加监控」**（点扩展图标的弹窗，在 1688 商品页截）。
5. **设置页 · 工作台/通知配置**（manage.html#settings）：可选，展示「Token 仅本机」等细节。
