# 1688 智能助手

> 监控 1688 商品的 SKU 变化并及时通知 · 揽收超时订单理赔申请框架 · 商品详情页一键导入自建工作台

1688 智能助手是面向 1688 买家的浏览器扩展，在你已登录的 1688 账号下工作，所有数据保存在你本机浏览器中，不上传到任何第三方服务器。

## 功能

- **SKU 变化监控（完整可用）**：监控你指定商品的全部 SKU——新增/删除、规格属性变化、库存数量增减、有货↔无货、价格变化；定时后台扫描 + 桌面通知 / Webhook 通知；首次扫描只建基准不打扰你；连续 3 次失败自动暂停并通知；支持历史快照查询与导出。
- **揽收超时理赔任务（只读模式，已适配真实 1688 页面）**：扫描揽收超时订单 → 识别并记录 → 只读探测申请入口 → 人工处理通道全链路已在真实页面实测通过（2026-11-16，端到端干跑：发现 → 去重 → 「需人工处理」→ 结果回读「平台驳回」，全程未提交真实理赔）。扩展**不会提交**真实理赔申请（该订单平台暂不受理且已有理赔记录；启用自动提交需你的单独授权 + 评审）；状态机、去重、重试（最多 3 次）、批次汇总通知、人工处理通道均已实现并经模拟数据验证。
- **商品导入工作台（增量功能）**：在 1688 商品详情页点击扩展图标，再点「📥 导入 1688」，预览商品数据（名称/价格/属性/SKU/图片），勾选确认后导入你**自建的工作台服务**；支持「已有同商品时更新还是仍然新建」的显式选择，杜绝重复商品。
- **数据与备份**：所有数据（订单、商品、SKU 快照、变化记录、日志、通知记录）保存在浏览器 IndexedDB；支持一键 JSON 导出/导入。

## 隐私与数据

- 扩展**不上传任何数据**给开发者，开发者不运营任何服务器。
- 除你主动点击的 1688 页面与你**自己在设置中填写并授权**的 Webhook / 工作台地址外，扩展不向其他任何地址发送请求。
- Token、Webhook 地址等敏感配置仅保存在你本机浏览器（chrome.storage.local / IndexedDB），不进日志。
- 完整隐私政策：<https://github.com/mufeng510/1688-helper/blob/main/docs/store/privacy-policy.md>

## 使用要求

- 已在 Chrome/Edge 登录 1688 买家账号；
- 监控/理赔识别/导入功能依赖当前登录态，不绕过、也无法绕过平台风控或验证码（遇到时会暂停并要求人工处理）；
- 理赔模块仅做揽收超时订单的发现与只读追踪，**不会提交真实理赔申请**；
- 「导入工作台」功能需要你自己部署的工作台服务（见仓库 docs/IMPORT_1688.md）。
